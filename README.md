> 🔨 **Build**
>
> Clone the repository and use the included Gradle wrapper.
>
> **Windows**
> ```bash
> gradlew build
> ```
>
> **Linux / macOS**
> ```bash
> ./gradlew build
> ```
>
> Build artifacts are generated in `build/libs/`.
>
> **Requirements**
>
> `Java 21+` · `Git` · `Internet connection`
>
> Internet access is required on the first build to download Gradle dependencies.
